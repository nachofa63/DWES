¿Qué protegió a los datos en la pregunta 9? 
La base de datos mediante la restricción de integridad referencial (Foreign Key), que impide borrar registros padres si tienen hijos asociados.

¿Qué habría pasado sin START TRANSACTION en la 10? 
Que el cambio a 0.00 se habría guardado de forma permanente e irreversible en la base de datos de inmediato (autocommit).

Prueba de CHECK y UNIQUE:

Sentencia de fallo por CHECK (ej: precio negativo): INSERT INTO producto (nombre, precio) VALUES ('Invalido', -5.00);

Sentencia de fallo por UNIQUE (ej: email duplicado en cliente): INSERT INTO cliente (nombre, email) VALUES ('Otro', 'ana@ejemplo.es');
